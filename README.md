# Linux-ROS2-Learning

A 30-day hands-on learning portfolio for robotics and embedded development.

## Schedule

2026-11-25 through 2026-12-24. Study for 60 minutes daily: Linux 25 minutes, ROS 2 25 minutes, reflection 10 minutes.

## Repository structure

- `linux/`: command line, processes, networking, build and debug exercises
- `ros2/`: nodes, topics, services and actions
- `tf2/`: frames and pose transformations
- `mini-projects/`: integrated robot pose visualization project
- `interview-notes/`: technical questions and answers
- `daily-log/`: evidence and reflections

See [ROADMAP.md](ROADMAP.md) and [PROGRESS.md](PROGRESS.md).

## Completion policy

All learning days start as Pending. Mark work Completed only after the learner runs it and records commands, results and a short explanation. Generated lesson material alone is not completion evidence.

## Environment

Linux distribution, ROS 2 distribution and hardware: not yet confirmed. Record exact versions before following installation or package instructions. No executable examples have been validated yet.

## Final project acceptance

Publish a reproducible robot pose visualization demo with a documented TF tree, a URDF model, RViz configuration, build/run instructions and observed results. Check transform composition/inversion numerically, explain source/target frames and handle unavailable or stale transforms.
